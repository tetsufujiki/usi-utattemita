# usi-utattemita

`utattemita.united-studio.com` のためのNext.jsプロジェクト。

このサイトは、rec.united-studio.com の置き換えではなく、
「歌ってみたい」という未確定の気持ちを、
予約・相談・料金確認へつなげるための軽い入口として制作する。

Primary Feeling: Playful Confidence

## 参照

- UDSL Core + Extensions Inventory Draft
- Utattemita Extension Brief Draft

## 開発

```bash
pnpm dev
pnpm typecheck
pnpm lint
pnpm build
```

## 初期構成

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- shadcn/ui（Radixベース）

本プロジェクトではまだ本格的なホームページのデザイン実装を行わない。次の制作ステップで、Utattemita Extension Briefを参照して実装を進める。
